# MeshCore Bot

Home Assistant add-on for the MeshCore radio bot. It runs the bot, keeps its database under `/data`, and adds a sidebar entry for the web viewer.

Set the radio connection in the add-on options. Other settings live in `config.ini`, which you can edit with the File Editor or Samba add-on. The add-on is built for 64-bit systems (amd64 and aarch64). The Documentation tab covers install, the connection options, backups, and publishing the viewer port.
